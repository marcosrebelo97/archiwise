## Instruções

Para rodar o projeto, é necessário ter o Node.js instalado. Caso não tenha, você pode baixar [aqui](https://nodejs.org/pt-br/download/).

### Instalação

```bash
npm install
# or
yarn
```

### Rodar o projeto

Para rodar o projeto, execute o comando abaixo e acesse [http://localhost:3000](http://localhost:3000) no seu navegador.

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```

Você pode começar a editar a página modificando `app/page.tsx`. A página é atualizada automaticamente conforme você edita o arquivo.

Este projeto utiliza [`next/font`](https://nextjs.org/docs/basic-features/font-optimization) para otimizar e carregar automaticamente a fonte Inter, uma fonte customizada do Google.
